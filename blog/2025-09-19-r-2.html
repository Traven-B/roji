Workflows in this Guide

  • Workflow 1: How to Add Styled Images to Your Post
  • Workflow 2: How to Use Data-Driven Content in Your Posts
  • Appendix: Cleaning Up Post Assets with find_widows

This guide walks through two common post workflows:

  1. Images + Stylesheets – fetching images into a per-post directory and creating a page-scoped stylesheet.
  2. Post Data – generating a sample data file with a rake task, and using ERB to inject YAML data as markdown content.

Each workflow shows how Roji’s per-post asset directories keep content structured, self-contained, and easy to manage.

Step 0: Install the tiny micro-optparse gem globally, if not already present:

bash gem list micro-optparse gem install micro-optparse

How to Add Styled Images to Your Post

Follow these steps to add styled images using the example files and scripts.

Step 1: Prepare Your Post Markdown

  1. Copy an example post markdown file to source/posts/.
    Navigate to the source/posts directory and do:

    cp ../../examples/example-post-with-images/example-with-styled-images-2025-08-28.html.md .

  2. Copy an example post markdown file to source/posts/.
    Navigate to the source/posts directory and do:

cp ../../examples/example-post-with-images/example-with-styled-images-2025-08-28.html.md .

Note the trailing dot indicating the current directory.

  1. This file contains YAML front matter and text to float some images around.

  2. Insert the markdown lines at the desired positions in your post. For example:

    ## The Ancient Period

>> [_![](posts/example-with-styled-images-2025-08-28/dorothy-toto.jpg){: .right .mb1 .mhnn #dorothy-toto}_](#dorothy-toto)
   From the fourth to the ninth century, Chinese culture strongly influenced the...

>> [_![](posts/example-with-styled-images-2025-08-28/dorothy-toto-2.jpg){: .left .mb1 .mhnn #dorothy-toto-2}_](#dorothy-toto-2)
   An increasing amount of land thus passed into true private holdings...

Step 2: Generate Image Markdown Lines

  1. Run the image processing script from source/posts/, supplying the relative input file:

bash ../../utils/do_images.rb ../../examples/example-post-with-images/input-for-do-images.txt > /tmp/mk_lines.txt

  1. The script copies source images into the post's image directory with unique names and outputs markdown lines linking to them.

  2. Review the generated lines in /tmp/mk_lines.txt.

Step 3: Add Markdown to Your Post

  1. Insert the markdown lines at the desired positions in your post. For example:

    ## The Ancient Period
   
>> [_![](posts/example-with-styled-images-2025-08-28/dorothy-toto.jpg){: .right .mb1 .mhnn #dorothy-toto}_](#dorothy-toto)
   From the fourth to the ninth century, Chinese culture strongly influenced the...
   
>> [_![](posts/example-with-styled-images-2025-08-28/dorothy-toto-2.jpg){: .left .mb1 .mhnn #dorothy-toto-2}_](#dorothy-toto-2)
   An increasing amount of land thus passed into true private holdings...

  2. Adjust classes (e.g., .left or .right) to float images as desired.

  3. Save the post.

Step 4: Update the Stylesheet

  1. Run the rake task to create the per-post stylesheet:

bash rake make_extra_css example-with-styled-images-2025-08-28.html.md

This generates:

text ../assets/stylesheets/additional_styles/posts/example-with-styled-images-2025-08-28.css.scss

  1. Append example CSS rules from examples/complete-scss-style-contents.css.scss.

  2. Copy the first line comment of the stylesheet into the post YAML front matter as stylesheet::

```yaml

title: Example with styled images date: 2025-08-28 21:52 CDT category: test tags: test stylesheet: additional_styles/posts/example-with-styled-images-2025-08-28 — ```

  1. Save both files.

Step 5: Build and Preview

Run middleman build (or equivalent) and preview the post.

Tip: After deleting the post, run rake find_widows to track leftover per-post assets.

How to Use Data-Driven Content in Your Posts

This workflow generates a data file with boilerplate ERB for inclusion in an otherwise empty .html.md.erb post.

Step 1: Prepare Your Post Markdown

Copy an example post:

bash cp ../../examples/example-post-using-data/example-using-data-2025-08-28.html.md.erb .

Step 2: Generate Data Directory

Run the rake task:

bash rake use_data example-using-data-2025-08-28.html.md.erb

This creates a YAML data file:

text ../../data/posts/example_using_data_2025_08_28/a.yml

Step 3: Inject ERB Code into the Post

  1. Edit a.yml to remove the code block after the data.
  2. Cut the code and paste it after the post's front matter.

erb <% elements = data.posts.example_using_data_2025_08_28.a %> <% current_page.data.summary = elements.map { |e| "### #{e[:name]}\n\n" }.join %>

  1. Save both files. A boilerplate copy remains at:

text ../../utils/use_data_separate_boilerplate.txt

Step 4: Stylesheet

Optional; usually no extra stylesheet is needed.

Step 5: Build and Preview

Run middleman build and preview.

Tip: Use rake find_widows after deleting a data-driven post to track leftover per-post assets.

Appendix: Cleaning Up Post Assets with find_widows

Both workflows create assets named after the post:

  • Workflow 1: per-post image directory and stylesheet.
  • Workflow 2: per-post data directory.

If a post is deleted, find_widows.rb finds leftover post assets for cleanup.

Run the Audit

bash rake find_widows

Example output:

text widowed image directories are: example-with-styled-images-2025-08-28 widowed style files are: example-with-styled-images-2025-08-28 no widowed DATA directories found

Remove Leftover Assets

bash rm -rf source/assets/images/posts/example-with-styled-images-2025-08-28 rm -f source/assets/stylesheets/additional_styles/posts/example-with-styled-images-2025-08-28.css.scss rm -rf data/posts/example_using_data_2025_08_28

Note: Data directories use underscores _ instead of hyphens - to work with Middleman’s data helper methods.

When to Use

  • After deleting test or example posts.
  • Periodically, to tidy up drafts or experiments.

Safety Tip: Use ls + tab completion before replacing with rm or rm -rf to avoid mistakes.
